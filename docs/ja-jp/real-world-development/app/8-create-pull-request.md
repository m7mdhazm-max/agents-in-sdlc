フィルターの実装、命令の更新、スキルの更新、品質保証 (QA) プロファイル、テストは、すべて 1 つのブランチに保存されています。まとめてレビューし、プルリクエストを作成しましょう。星評価のプルリクエスト (PR) は自分でマージしました。今回は **Agent Merge** にその管理を任せます。

> [!NOTE]
> 通常は機能、命令の更新、スキルの更新、QA エージェントを複数の PR に分けます。このワークショップでは、フィルターと品質ワークフロー全体を 1 つのセッションとブランチにまとめ、1 つの PR に含めて簡潔に進めます。

このレッスンでは、次の操作を行います。

- Agent Merge と、マージ ライフサイクルを自動化する方法を学ぶ。
- 機能全体の PR と検証結果を確認する。
- レビュー後にのみ Agent Merge に許可を与え、PR がマージされたことを確認する。

## シナリオ

フィルター機能の開発では、Copilot を使って計画、実装、検証を行いました。Tailspin Toys は、マージ許可を開発者の管理下に置いたまま、残りの PR 作業を自動化したいと考えています。

## Agent Merge の概要

**Agent Merge** を使うと、GitHub Copilot app でプルリクエストをマージするまでの残りの作業を自動化できます。有効にすると、アプリのセッションがプルリクエストを確認し、失敗した継続的インテグレーション (CI) チェックの修正、レビュー コメントへの対応、必要に応じたリベースなど、マージを妨げている問題に対処します。GitHub が許可すると、プルリクエストをマージします。バックグラウンドで実行され、アプリを再起動しても継続し、PR がマージされると自動的に停止します。

ここまでは自分で **Merge pull request** を選択してきました。Agent Merge にその作業を任せることもできますが、コードの編集とマージには明示的な許可が必要です。マージを許可する前に、実行可能な操作と作業内容をレビューします。

## Agent Merge で PR を管理する

コードの作成とレビューが終わったら、Agent Merge に PR の残りのプロセスを任せます。

1. エージェント ピッカーで **Default agent** を選択します。
2. **Create PR** の横にあるドロップダウンを選択します。
3. **Agent Merge** を選択します。ボタンが **Agent Merge** に変わります。
4. **Agent Merge** ボタンを選択して処理を開始します。ドロップダウンから選択するだけでは開始されません。

Agent Merge が開始され、次の処理を行います。

- タイトルと説明を付けてプルリクエストを作成します。
- issue からセッションを開始した場合は、説明本文で関連する issue を参照します。
- リベースを行うか、ターゲット ブランチとのマージ競合に対処します。
- CI を監視し、すべてのチェックが成功することを確認します。
- 他の開発者や Copilot code review からのフィードバックを監視し、コメントを解決するための変更を行います。
- すべてが成功すると、PR を自動的にマージすることもできます。

必要なチェックがすべて成功したら、Agent Merge に PR のマージも行わせましょう。

5. マージを許可する前に、PR の差分と検証結果をレビューします。
6. **Agent Merge** の横にあるドロップダウンを選択します。
7. **Merge pull request** にチェックが付いていることを確認します。
8. 次のように、マージを明示的に依頼します。

    ```plaintext
    Merge the PR once all required checks and approvals pass. Do not bypass repository protections.
    ```

9. 進捗を確認し、報告された問題を解決します。続行する前に PR の状態が **Merged** であることを確認してください。マージ権限が有効になっていることや、エージェントが実行中であることだけではマージ完了の確認になりません。

> [!IMPORTANT]
> Agent Merge は、リポジトリの保護や権限不足を回避しません。続行する前にそれらの問題を解決してください。

## まとめと次のステップ

コードの生成、テストと検証、プルリクエストの処理など、開発プロセスの一部を自動化しました。具体的には、次の操作を行いました。

- Agent Merge と、マージ ライフサイクルを自動化する方法を学んだ。
- 機能全体の PR と検証結果を確認した。
- レビュー後にのみ Agent Merge に許可を与え、PR がマージされたことを確認した。
